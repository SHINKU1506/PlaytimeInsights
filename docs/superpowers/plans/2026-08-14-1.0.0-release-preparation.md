# Playtime Insights 1.0.0 Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare and publish the accepted architecture, responsive visual, and sidebar performance work as a consistent 1.0.0 release without deploying it locally.

**Architecture:** Keep release activation data in the repository-owned installer manifest and keep AddonDatabase catalog metadata stable. Separate verifiable release preparation from external actions: package creation, Git tag, GitHub Release upload, remote `main` activation, and optional catalog screenshot updates remain explicit gates.

**Tech Stack:** .NET Framework 4.6.2, C# 7.3, WPF, Playnite SDK 6.16, YAML manifests, PowerShell, Playnite Toolbox.

## Global Constraints

- Version is `1.0.0`; assembly version is `1.0.0.0`.
- AddonId remains `PlaytimeInsights_7094cd6b-d3a4-41d0-b7c3-f0cc535a9efd`.
- `RequiredApiVersion` remains `6.16.0` unless dependency evidence requires a change.
- Keep the 0.9.8 package in the installer manifest below 1.0.0.
- Package, tag, publish and activate 1.0.0 only after each preceding gate passes; do not deploy, launch Playnite,
  edit AddonDatabase, or write user data.
- Preserve the untracked `perf_test.ps1`.
