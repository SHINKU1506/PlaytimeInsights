# Playtime Insights 1.1.0

Playtime Insights 1.1.0 集中改善 Dashboard 的信息层级、长区间性能和不同窗口宽度下的可读性，
不改变既有本地会话数据格式或隐私边界。

## 主要变化

- 重新组织 8 张响应式指标卡，拆分主值与单位，只高亮当前快捷范围；
- 趋势图隐藏未来尾部对有效数据比例的干扰，并补齐全未来范围、单点范围的坐标轴和交互表现；
- Weekday、Hour 与 Week×Hour 分布图按各自模块视口独立适配，在窄宽度下选择滚动或居中；
- Calendar 热力图改为轻量 Button 和 Recycling 周列虚拟化，月份轴与内容滚动同步；
- 修正 Week×Hour 强度填充未覆盖完整格子的视觉问题；
- 优化 10 年 / 100k 会话分析、跨时区分配与长范围热力图布局成本；
- 保留 schema 1–4 升级、跨午夜和 DST 口径、导入导出、备份恢复、中英文资源与键盘 Button 语义。

## 升级说明

可以从 1.0.0 直接升级。插件数据继续存放在 Playnite 的独立 `ExtensionsData` 目录；安装或更新
PEXT 时不会把会话数据打包进插件安装目录。更新完成后需要按 Playnite 提示重启客户端。

## 已知边界

- 实际读屏器播报未执行人工验收；自动化只覆盖 Automation Name 与焦点/命令契约；
- 极长时长保持单行胶囊显示，不在胶囊内换行；
- 正式包、最终 SHA-256 和公开下载地址以 GitHub Release 附件及发布检查清单为准。
