# Playtime Insights 版本路线与技术设计

更新日期：2026-07-28

## 1. 产品目标

Playtime Insights 是一个离线优先的 Playnite 游玩时间统计插件。它需要同时回答：

1. 我总共玩了多久、哪些游戏玩得最多；
2. 指定日期范围内玩了多久、时间分布如何；
3. 每次实际游戏会话发生在什么时候、持续多久；
4. 日、周、月、年之间的趋势有什么变化。

默认使用 Playnite 客户端内的原生界面。只有原生 WPF 无法经济实现复杂交互图表时，才允许使用
Playnite 内嵌的本地 WebView；即使使用 WebView，资源也必须随插件离线打包，禁止依赖远程网站。

## 2. 数据口径

### 2.1 累计口径

数据来源为 Playnite `Game.Playtime`、`Game.PlayCount` 和 `Game.LastActivity`。

适用范围：

- 所有游戏累计总时长；
- 游戏累计时长排名；
- 安装插件前已经存在的总时长。

限制：Playnite 累计数据不能还原过去每一次会话，也不能可靠分配到历史日期。

### 2.2 会话口径

数据来源为插件捕获的 `OnGameStarted` 和 `OnGameStopped`。停止事件提供
`ElapsedSeconds`，这是指定时间范围统计、热力图和会话排名的权威数据。

适用范围：

- 每日、每周、每月、每年和自定义范围统计；
- 会话次数、平均会话、最长会话；
- 活跃天数、连续游玩天数；
- 星期和小时分布。

### 2.3 展示原则

- 累计数据和精确会话数据必须分别标注；
- 不把未知历史累计时长全部放到 `LastActivity`；
- 导入数据需要标记来源和可信等级；
- 时间范围图表默认只使用精确会话。

## 3. 总体架构

```text
Playnite lifecycle events
        |
        v
SessionTracker ---- active sessions
        |
        v
SessionRepository ---- sessions.json / backup
        |
        v
AnalyticsService ---- range split / aggregation / ranking
        |
        v
DashboardViewModel
        |
        v
Native WPF Sidebar View
        |
        +---- optional local WebView chart host (post-0.5 only)
```

### 3.1 插件类型

- C# `GenericPlugin`
- 目标框架：正式构建目标为 .NET Framework 4.6.2
- SDK：PlayniteSDK 6.16.x
- 入口：Desktop Sidebar `View`
- 设置：Playnite 原生扩展设置页

### 3.2 模块边界

| 模块 | 职责 |
|---|---|
| `PlaytimeInsights` | Playnite 生命周期、侧边栏注册、依赖组装 |
| `SessionRepository` | 加载、原子保存、备份、数据版本 |
| `AnalyticsService` | 时间范围聚合、格式化、游戏排名 |
| `DashboardViewModel` | 将统计结果转换成可绑定视图数据 |
| `PlaytimeInsightsDashboardView` | 原生 WPF 仪表盘 |
| `PlaytimeInsightsSettings` | 会话开关、显示天数、排名数量 |

## 4. 存储设计

0.1 使用插件专属用户数据目录中的单一 JSON 文档：

```text
ExtensionsData/<plugin-id>/
  sessions.json
  sessions.backup.json
```

会话字段：

| 字段 | 说明 |
|---|---|
| `Id` | 会话唯一 ID |
| `GameId` | Playnite 数据库游戏 ID |
| `GameName` | 记录时名称快照 |
| `StartedAtUtc` | UTC 开始时间 |
| `EndedAtUtc` | UTC 结束时间 |
| `ElapsedSeconds` | Playnite 报告的实际持续秒数 |
| `StartUtcOffsetMinutes` | 开始时本地 UTC 偏移 |
| `EndUtcOffsetMinutes` | 结束时本地 UTC 偏移 |
| `ManuallyStopped` | 是否由用户手动停止追踪 |
| `Source` | `Tracked`、`Imported`、`Manual`、`Recovered` |
| `SchemaVersion` | 会话结构版本 |

保存策略：

1. 先写 `sessions.json.tmp`；
2. 已有正式文件时使用替换操作，同时保留最近备份；
3. 首次保存时将临时文件移动为正式文件；
4. 读取失败时不覆盖损坏文件，只记录错误。

0.5 后评估按年份分片的 JSONL。只有性能测试证明 JSON 存储不足时才引入数据库，以避免
Playnite 插件程序集版本冲突。

## 6. 版本路线

### 0.1 — 原生技术验证（已完成）

完成标准：

- 插件能由 Playnite 加载；
- 侧边栏出现“Playtime Insights”；
- 点击后显示 WPF 原生仪表盘；
- 游戏停止后生成一条精确会话；
- 重启 Playnite 后会话仍存在；
- 累计时长排名来自 Playnite 数据库；
- 插件不加载任何网页。

范围：

- 会话记录开关；
- 最近天数设置；
- Top 游戏数量设置；
- 单文件 JSON 持久化和备份；
- 最近 N 天柱形概览；
- 累计排名；
- 基础中文界面。

不在范围：

- 历史导入；
- 会话编辑；
- 自定义日期；
- 热力图；
- 崩溃会话恢复；
- Fullscreen 模式。

### 0.2 — 数据可靠性（已完成）

- 持久化 active session；
- Playnite 或系统异常退出后的恢复向导；
- 跨午夜按实际重叠时间拆分；
- 夏令时、闰日、跨年测试；
- 游戏删除、改名后的快照展示；
