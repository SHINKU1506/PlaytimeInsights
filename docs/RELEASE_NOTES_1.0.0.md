# Playtime Insights 1.0.0 发布说明

发布日期：2026-08-14

## 重点更新

- 完成原生 WPF 架构重构，交互、会话工作流、刷新策略和 Dashboard 分析职责边界更清晰；
- 九张指标卡支持 1–4 列响应式布局、同排等高和末行居中，并改善长文本与主题可读性；
- Dashboard 筛选只刷新受影响投影，减少聚合、排名等局部切换的重复分析；
- 侧边栏重复进入复用 Dashboard View，避免重复构造完整视觉树；
- 封面缩略图使用共享、有限容量、可失效的冻结图像缓存，降低重复解码开销；
- 保持全部统计口径、schema 1–4 升级、导入导出、备份恢复、隐私和中英文界面兼容。

## 升级

可从 0.9.8 原位升级。插件更新不会主动删除或迁移用户会话文件；发布前仍需完成版本专属升级验收，
并确认 `ExtensionsData` 联合指纹在无用户操作时保持不变。

## 已知边界

- 插件仅支持 Playnite Desktop；
- 辅助文字实际对比度取决于 Playnite 主题，1.0.0 发布前需完成目标主题与 DPI 客户端矩阵；
- 首次完整载入和大范围完整刷新仍会执行同步分析，后续异步可取消刷新属于独立路线。
