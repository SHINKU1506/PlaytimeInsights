# Playtime Insights

Playtime Insights 是一个完全本地运行的 Playnite 游玩时间分析插件。

当前开发版本：`0.9.2`

当前版本包含以下核心链路：

- 监听 Playnite 游戏开始和停止事件；
- 将完整游戏会话保存到插件专属数据目录；
- 在 Playnite Desktop 客户端侧边栏打开原生 WPF 仪表盘；
- 展示累计游玩时长、已记录会话、最近活动和累计时长排名；
- 不加载远程网页，不发送用户数据。
- 运行中的会话每分钟写入检查点；
- 异常退出后按最后检查点自动恢复；
- 跨午夜会话按本地自然日拆分；
- 重复停止事件去重；
- 主数据损坏时从最近备份恢复。
- 今天、本周、本月、本年和自定义日期范围；
- 日、周、月、年四种原生柱状聚合；
- 区间时长、会话数、活跃天数、平均和最长会话指标；
- 按时长、会话数、活跃天数、平均或最长会话切换区间排名；
- 独立保留 Playnite 所有游戏累计时长和累计排名；
- 区间与累计排名显示 Playnite 本地库封面缩略图，缺失封面时保持固定布局；
- 排名前三名使用金、银、铜数字勋章，每个条目以半透明进度条显示其占当前口径总游玩时长的比例；
- 默认使用 ISO 周一，可在设置中切换为系统地区的每周第一天。
- 原生日历热力图；
- 同一聚合序列的原生柱形图与折线趋势；
- 热力格、柱形和折线点的精确 tooltip；
- 点击任一图形数据点钻取到对应日期范围的会话列表。
- 会话明细固定最大高度并独立滚动，使用 Recycling 虚拟化；
- 首批显示 100 条会话，每次按需加载更多 100 条。
- 聚合粒度默认使用“自动”：年按月，月及以下按日，自定义范围按跨度选择；
- 用户可随时手动覆盖为日、周、月或年。
- 独立的“Playtime Insights · 会话”原生侧边栏；
- 按游戏/当前元数据关键字和会话来源筛选；
- 元数据维度可选择库来源、Playnite 来源、发行商、标签、类型、分类和安装状态；
- 元数据维度支持开发者；
- 原生补录和编辑会话；
- schema 4 软删除、查看已删除、恢复和导入审计；
- 200 条分批、Recycling 虚拟化的最新会话列表；
- 将当前筛选结果安全导出为 UTF-8 CSV 或版本化 JSON；
- 原生预览并导入 Playtime Insights JSON/CSV；
- 兼容 GameActivity 单游戏 JSON 和会话明细 CSV；
- 导入验证、重复跳过与可保存错误报告；
- 完整手动备份、恢复和重建存储索引；
- 导入、恢复和重建前自动创建时间戳回滚备份。
- 分析页按当前 Playnite 库来源、开发者、类型、标签或安装状态筛选全部指标、图表、排名和会话钻取；
- 原生星期分布、24 小时时段分布与星期 × 小时二维热力图；
- 点击星期分布可将 24 小时图切换为对应星期，再次点击恢复全部星期；
- 星期和 24 小时柱图只保留横轴刻度，具体时长改由悬浮提示显示；柱体使用顶部圆角的蓝紫渐变；
- 星期 × 小时与日历热力格放大并居中，零时长格使用明确的深灰底色建立连续网格；
- 聚合趋势使用原生 WPF 单调贝塞尔曲线和半透明渐变面积，圆点点击钻取保持不变；
- 0.9.3 聚合区只保留自适应面积趋势图：无横向滚动，X 轴自动稀疏，长跨度自动隐藏节点并收细线条；
- 趋势图悬停显示垂直 Crosshair 和包含周期、游戏摘要、总时长的半透明卡片，点击可继续下钻；
- 自适应趋势保持蓝到霓虹紫的渐变线和渐隐面积；日期标签按真实文字宽度防碰撞并保留末期标签；
- 主界面的操作说明和统计口径统一折叠到原生 `?` Tooltip；空会话下钻区在选择图表前保持隐藏；
- 按日聚合柱形提供独立的 `#4A90E2` 到透明渐变对比方案，使用 2 像素圆角；
- 会话跨小时按实际墙钟区段分配，分片后总秒数严格守恒；
- 最长及当前连续游玩天数；
- 上一等长区间环比和去年同期同比；
- 零秒、未来时间、结束早于开始、超长等异常会话只读提示。
- 保存不含游戏名称、会话时间、用户路径或标识符的本地诊断报告；
- 设置页和 `PRIVACY.md` 明确本地处理、文件写入与诊断范围；
- 5,000 游戏、10 万会话、十年范围的分析与 schema 4 JSON 加载压力验证；
- schema 1–4 到当前 schema 4 的无损升级回归。
- 完整 `zh_CN` 与 `en_US` 原生资源，英文为安全回退资源；
- 仪表盘、会话管理、编辑、导入预览、设置和原生文件/确认对话框均使用本地化文本；
- 按钮访问键、明确 Tab 顺序、初始焦点和循环键盘导航；
- 主要输入、筛选、列表、按钮和状态区域提供屏幕阅读器自动化名称；
- 中英资源键对称、原生视图无硬编码中文属性及无障碍标记均纳入自动化回归。
- 两个热力图的星期标签跟随 Playnite 界面资源，不再错误跟随 Windows 地区；
- 英文月份标题使用插件控制的数字格式，不再受 Windows 地区月份名称影响；
- 分析与会话管理使用独立的透明侧边栏图标，并保持同一“游玩时间”视觉体系；
- 原生窗口按有效工作区约束大小，覆盖 100%–200% DPI 下的可见范围；
- 主视图、会话列表和导入预览在窄窗口或长文本下提供换行或横向滚动；
- 主题画刷限制为默认主题和 Seaside 均提供的 Playnite 公共资源；
- 两个主页面统一标题导航标识、面板圆角、字段标签和间距，保留原生 WPF 与 Playnite 动态主题；
  仅排名前三勋章使用固定的金、银、铜语义色；
- 分析范围摘要提升为面板信息块，星期选择使用克制的主题描边并保留鼠标、键盘和屏幕阅读器交互；
  取消选择后选中蓝条会立即消失，键盘焦点使用独立细框；
- 指标卡片使用统一的 12 像素横向和纵向间距，窗口缩放与换行时不会互相黏连；
- 顶部 9 张指标卡统一为 26pt 粗体主数字、低对比度说明和单色原生字形；环比、同比以卡内
  趋势 Tag 合并到“区间游玩时长”，悬浮可查看百分比与基准区间；
- “当前连续游玩”主数字只显示天数，截止日期移到下方辅助文字，避免较长地区日期挤压主值；
- 会话页区分常用操作与数据工具，列表提供固定列头、行分隔、悬停和左侧主题色选中反馈；
- 图表点击后的会话钻取使用固定宽度 GridView 列，游戏、开始时间、时长和来源保持垂直对齐；
- 排名时长占比使用 12% 透明度蓝色作为整行底层填充，徽章、封面和文字悬浮在进度背景之上；
- 0.1–0.9 设置默认值、schema 1–4 数据、主要错误路径及中英格式占位符纳入最终矩阵。

## 数据口径

- “累计游玩时长”和“累计排名”读取 Playnite 的 `Game.Playtime`。
- “插件记录时长”和“最近活动”只读取插件安装后捕获的精确会话。
- 插件不把安装前的累计时长伪造为历史日期记录。
